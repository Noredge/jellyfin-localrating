# 测试说明

仓库仅保留当前版本使用的回归测试，所有测试账号、媒体及评价均为合成数据。

## 后端与构建

需要 `global.json` 指定的 .NET SDK。在仓库根目录运行：

```powershell
.\scripts\verify.ps1
```

SDK 不在系统搜索路径中时，使用 `-Dotnet 'C:\path\to\dotnet.exe'` 指定路径。

验证包括依赖还原与审计、Release 构建、格式检查、至少 69 项后端测试、内嵌网页资源和共享程序集版本检查。持续集成使用锁定模式还原依赖。

后端测试覆盖身份与可见性、逐用户隔离、评分边界、筛选排序与分页、SQLite 持久化及版本处理、部分保存失败、网页注入与缓存、账号/媒体库范围及响应评分映射。

## 网页交互

需要 Node.js。启动仅绑定本机回环地址的测试页面：

```powershell
node tests/web/server.cjs
```

| 页面 | 检查方法 |
| --- | --- |
| `http://127.0.0.1:18767/` | 点击运行按钮，执行 16 项详情、筛选、草稿和保存回归 |
| `http://127.0.0.1:18767/narrow` | 在 360px 浅色页面中重复上述 16 项检查 |
| `http://127.0.0.1:18767/configuration` | 点击设置测试按钮，执行 6 项设置读写及请求隔离检查 |

测试页面加载真实产品脚本、样式和设置 HTML，通过合成接口模拟网络延迟、认证失败及写入失败，不连接实际 Jellyfin 服务器。检查长评价随页面增长、固定保存操作、主题对比度及横向溢出。测试结束后按 `Ctrl+C` 关闭服务。

## 实际安装验收

界面或部署相关修改应在受影响的真实环境验证：

- 备份后安装、重启，核对最新启动日志中的版本与插件状态。
- 检查已有评分和评价、评分保存/清除、评价保存失败后的草稿及重试。
- 检查两个账号之间的隔离、隐藏媒体的访问限制、筛选分页及详情页返回。
- 检查原生主题、ElegantFin、桌面及窄屏布局，确认卡片仍可点击。
- 设置变更后刷新，确认开关和账号/电影库范围实际保存。

只修改文档无需重复真实部署。合成测试和网页尺寸模拟不能代替物理电视或手机验收；不把未执行的检查记为通过。数据操作遵循 [备份与恢复说明](BACKUP_AND_RECOVERY.md)。
