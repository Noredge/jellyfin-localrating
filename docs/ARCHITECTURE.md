# 架构与数据边界

## 组件

| 组件 | 职责 |
| --- | --- |
| `LocalRatingController` | 身份与可见性检查、评分及评价接口、完整媒体库筛选和分页 |
| `LocalRatingRepository` | 插件 SQLite 初始化、结构版本及逐用户评价存储 |
| `LocalRatingStartupFilter` | 在网页响应中注入内嵌脚本和样式，不修改安装文件 |
| `CompatibilityFilter` / `CompatibilityDtoService` | 在授权范围内处理个人评分排序，并仅为最终页生成和调整响应对象 |
| `localrating.js` / `localrating.css` | 评分、评价草稿、失败重试、卡片徽章和媒体库界面 |
| `configuration.html` | 管理员配置实验功能的开关、账号与电影库范围 |

## 身份与存储

- 身份来自 Jellyfin 认证的 `Jellyfin-UserId` 声明，客户端不能选择其他用户身份。
- 单项、批量及媒体库查询均遵守可见性限制；缺失或不可见项目按未找到处理。
- 个人整数评分保存在 Jellyfin `UserData.Rating`；评价保存在数据目录下的 `localrating/localrating.db`。
- 浏览器缓存按账号隔离，评价草稿按服务器、用户和项目保存在当前标签页的会话存储中。账号或服务器变化时清理旧范围。
- 不写 NFO、媒体目录或共享评分，不依赖外部服务。

## 保存与查询

评分和评价使用独立保存接口，评分操作不提交未完成的评价。组合保存接口若只成功写入一部分，会返回 HTTP 503，并用 `RatingSaved` 和 `ReviewSaved` 表明结果；不能把部分成功显示为全部成功。

评价保存失败时保留输入，允许重试；保存期间的新输入不能被较早请求的响应覆盖。放弃修改后的撤销只恢复草稿，不写入服务器。

评分筛选包含端点并排除未评分项目。完整候选集先按权限和评分筛选、排序，再计算总数和分页；同分使用确定性的次级顺序，避免跨页跳动。

## 实验性跨客户端兼容

兼容功能默认关闭，只有管理员选定的认证账号和电影库组合可以启用。支持指定电影库的递归电影列表、按 `CommunityRating` 排序以及附加 `SortName` 的请求。

响应中的社区评分取自当前用户自己的评分，未评分项目返回空值并排在最后；数据库中的公共评分不变。个人响应禁止共享缓存，关闭功能后恢复原生响应。

集合分组、混合媒体库、其他组合排序和详情页保留原生行为。Android TV 的请求形式已覆盖，物理电视、所有第三方客户端及真实大库性能不属于已完成的验收范围。

## 维护约束

数据库结构变化需要迁移、数据保留测试及恢复说明。Jellyfin 网页结构变化需要重新验证挂载点和布局。仅构建成功不能替代实际安装、重启及数据检查，具体方法见 [测试说明](TESTING.md) 和 [备份与恢复](BACKUP_AND_RECOVERY.md)。
