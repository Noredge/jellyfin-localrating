# Jellyfin 个人评分与评价插件

Local Rating 为 Jellyfin 提供私有的个人评分、文字评价和按评分筛选影片的功能。每位用户只能查看和管理自己的评分与评价，数据保存在本地服务器，无需外部服务。

当前版本：**0.6.1**。仅支持 **Jellyfin 12.0.0**，不兼容旧版服务器。目前界面语言为中文。

## 功能

- **个人评分**：在影片详情页选择 1–10 分，点击即保存，也可以清除评分；海报卡片显示个人评分徽章。
- **文字评价**：直接编辑，手动保存，支持最多 4000 字符；显示创建和最后编辑时间，长文随页面展开。
- **评分筛选与排序**：支持已评分、未评分、等于、低于或等于、高于或等于及评分区间，并可按个人评分升序或降序排列。
- **草稿恢复**：同一标签页内切换页面或刷新后可恢复未保存内容；保存失败时保留输入并提供重试提示。
- **主题与布局适配**：适配 Jellyfin 原生界面、ElegantFin、浅色与深色主题，以及桌面和窄屏布局。
- **实验性跨客户端排序**：可为指定账号和电影库启用个人评分映射，让支持的客户端通过社区评分排序使用个人评分。

## 安装

从仓库的 [自动构建页面](https://github.com/Noredge/jellyfin-localrating/actions) 下载成功运行所生成的安装包，或按照下文从源码构建。自动构建产物中包含 `LocalRating_0.6.1.0.zip`。

1. 停止 Jellyfin，确认服务器进程已经退出。
2. 备份完整的 Jellyfin 数据目录，包括评价数据库及可能存在的 WAL、SHM 文件。升级时，将旧版插件文件夹移到插件目录之外并保留。
3. 解压安装包，将其中的 `Local Rating_0.6.1.0` 文件夹放入 Jellyfin 的 `plugins` 目录。Windows 默认位置如下：

   ```text
   C:\ProgramData\Jellyfin\Server\plugins\Local Rating_0.6.1.0\
   ```

4. 启动 Jellyfin，在管理控制台的插件列表中确认 **Local Rating** 已正常加载。
5. 在网页客户端按 `Ctrl+F5` 刷新，打开影片详情页即可看到“我的评分”面板。

安装目录因部署方式而异，请以实际服务器路径为准。升级和恢复的完整步骤见 [备份与恢复说明](docs/BACKUP_AND_RECOVERY.md)。

## 使用

### 评分与评价

点击分数即可保存评分，点击“清除评分”可取消评分。评分和评价分别保存，选择分数不会提交尚未保存的评价。

在评价框内直接输入，点击“保存评价”，或使用 `Ctrl+Enter` / `Command+Enter` 保存。点击“放弃修改”会恢复已保存的内容，随后有 10 秒时间可以撤销；撤销只恢复草稿，不会自动保存。继续输入或离开页面会结束这次撤销机会。

草稿按服务器、账号和影片隔离，仅用于当前标签页内的恢复。关闭标签页可能丢失草稿，草稿也不会同步到其他设备；需要保留的评价请及时保存。

### 筛选与排序

在电影库的个人评分控件中选择条件，例如：

| 目标 | 筛选方式 |
| --- | --- |
| 查找 8 分影片 | 等于 8 |
| 查找 6 分及以下影片 | 低于或等于 6 |
| 查找 8 分及以上影片 | 高于或等于 8 |
| 查找 7–9 分影片 | 评分区间 7–9 |
| 查找尚未评分的影片 | 未评分 |

数值筛选包含边界值，并排除未评分影片。筛选和排序在服务器端完成后再分页，每页最多 100 项。进入详情页后返回会保留筛选条件；恢复默认后回到 Jellyfin 原生列表。

### 实验性跨客户端排序

此功能**默认关闭**。在“管理控制台 → 插件 → Local Rating → 设置”中选择账号与电影库组合，启用后保存。

启用后，插件在受支持的列表响应中，将当前用户的个人评分临时作为社区评分（`CommunityRating`）返回。客户端选择“社区评分”排序即可使用该结果；如果菜单为英文，对应选项是 `Community Rating`，不是家长分级。未评分影片排在最后。

功能只作用于选定范围内、符合条件的电影列表请求，不会修改数据库中的公共评分。关闭后恢复原生响应，客户端可能需要刷新。

目前支持指定电影库的递归列表，以及按社区评分排序、可附加名称排序的请求。集合分组、混合媒体库、其他组合排序和详情页仍保持原生行为。已覆盖 Jellyfin Android TV 的请求形式，**尚未完成电视实机验证，不能保证所有客户端均可使用**。详细边界见 [架构与兼容说明](docs/ARCHITECTURE.md)。

## 数据与隐私

- 评分保存在 Jellyfin 原生的 `UserData.Rating` 中，卸载插件后仍然保留。
- 评价保存在 Jellyfin 数据目录下的 `localrating/localrating.db` 中，按用户隔离。
- 所有读写均需要 Jellyfin 身份认证，且只能访问当前用户有权查看的媒体。
- 不调用外部元数据、统计或云同步服务，不修改 NFO 文件、媒体目录或数据库中的公共评分。
- 网页脚本和样式随插件内嵌，通过响应注入加载，不直接修改 Jellyfin 网页客户端的安装文件。

当前不提供共享评价、评分统计、导入导出或独立的电视端评价界面。

## 从源码构建

需要 .NET SDK **10.0.400** 和 PowerShell。插件目标框架为 `net10.0`，依赖版本由项目与锁文件固定。

在仓库根目录运行完整验证：

```powershell
.\scripts\verify.ps1
```

验证包括依赖还原与审计、构建、格式检查、自动测试、内嵌资源和共享程序集版本检查。持续集成使用锁定模式还原依赖。

生成安装包：

```powershell
.\scripts\package.ps1
```

打包脚本会先执行验证，成功后生成 `outputs/LocalRating_0.6.1.0.zip`。数据库、本地备份和构建产物均不纳入 Git。

如果 `dotnet` 不在系统搜索路径中，可以为上述脚本传入 SDK 的完整路径：

```powershell
.\scripts\verify.ps1 -Dotnet 'C:\path\to\dotnet.exe'
.\scripts\package.ps1 -Dotnet 'C:\path\to\dotnet.exe'
```
